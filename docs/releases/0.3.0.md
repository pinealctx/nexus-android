# Android 0.3.0：Agent 会话工具与消息查找

日期：2026-09-09

## 功能

- [x] 依据协议 `AccountType` 识别 Agent 私聊，不依据昵称猜测身份。
- [x] 聊天页提供 Agent 工具面板，展示服务端配置的命令与描述；输入 `/` 时按命令名或描述筛选。
- [x] 选择命令仅填入草稿并定位光标，保留原有参数或正文，由用户确认发送；命令仍是标准 TEXT 消息。
- [x] 对启用 Mini App 的 Agent 提供会话内入口，复用带会话上下文的启动凭证与现有 WebView/bridge 流程。
- [x] Agent 信息先读缓存再刷新；离线刷新失败有重试入口，不清空已缓存工具。
- [x] 会话搜索提供防抖、加载、空结果、失败重试和每页 30 条的分页，拒绝旧查询结果覆盖新查询。
- [x] 搜索按字面匹配 `%`、`_`、反斜杠，摘要围绕命中位置截取并高亮关键词。
- [x] 点击结果定位原消息并短暂高亮；优先读取本地历史，定位失败不再遗留加载状态。

## 实现边界

本版不改变技术栈、公开协议或数据库版本。命令、Agent 类型、Mini App 开关均来自现有协议与服务端数据，不硬编码业务命令或应用地址。工具只针对 Agent 私聊，群聊提及仍沿用 0.2.0 行为。

搜索范围是**本设备已保存的消息**，不是服务端全文检索；界面明确提示此范围。全文搜索使用现有 SQLite 字段，不新增 FTS 索引。结果定位沿用最多 20 页的有界历史加载，超出范围或消息不可用时提供提示。持续新增或删除消息期间，偏移分页不是服务端快照。

## 验收

1. 打开 Agent 私聊，点击工具按钮，确认命令和 Mini App 开关与服务端配置一致；普通联系人不显示 Agent 工具。
2. 输入 `/` 或命令的一部分，选择命令，确认输入框保留参数、光标在命令之后，且没有自动发送。
3. 主动发送命令，确认 Agent 正常响应；打开 Mini App，检查会话上下文及现有权限流程。
4. 在搜索栏快速更换关键词，检查旧结果不闪回；关闭搜索再打开，恢复未输入状态。
5. 搜索超过 30 条结果的关键词，逐页加载；搜索 `%`、`_` 时只匹配对应字符。
6. 点击较早的结果，确认返回时间线、滚动与高亮；断网时缓存结果仍可查询，定位失败给出提示。

自动化覆盖命令规范化/筛选/草稿、UTF-16 摘要、防抖与过期响应、分页与失败重试、SQLite 字面匹配及 Compose 搜索交互。真实 Agent 响应与 Mini App 服务端启动仍需登录 dev 账号联调，组件测试不替代端到端验收。
