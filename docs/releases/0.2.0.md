# Android 0.2.0：群聊提及与富文本

日期：2026-09-09

## 功能

- [x] 群聊输入 `@` 显示成员候选，支持筛选、所有人、加载与重试状态。
- [x] 按用户 ID 保存提及，支持同名成员、光标插入、emoji、编辑和回复发送。
- [x] 输入框高亮有效提及；修改提及文字后移除原实体，避免错误通知。
- [x] 点击普通文本消息中的提及查看成员资料，提供加载和重试反馈。
- [x] 普通文本识别 HTTP(S)/www 链接，接收 URL、邮箱、电话、话题、粗体、斜体和代码实体。
- [x] 收发、编辑、重试及内存草稿保留文本 entities；Room 9 → 10 迁移保留现有消息和待发送队列。

## 实现边界

协议继续使用 `nexus-proto` 的 `MessageEntityType`、`MentionEntity` 和 `UrlEntity`，不引入新消息类型。实体偏移沿用桌面 JavaScript 的 UTF-16 索引；Android 拒绝越界、溢出与拆分代理对的范围。

本版富文本实体交互适用于 TEXT 消息。Markdown/STREAM 继续沿用现有渲染器，未增加 Markdown 编辑工具栏、话题搜索或 Agent slash commands。草稿沿用会话内存保存方式，退出进程后不恢复；已进入发送队列的消息及实体持久化保存。

## 验收

1. 在群聊输入 `@`，筛选并选择一个成员，检查光标位于昵称后且提及高亮。
2. 在提及前插入 emoji 或文字，发送后点击提及确认对应用户；同名成员按各自 ID 区分。
3. 编辑消息、删除提及部分文字，再发送，确认失效提及不再高亮或通知原成员。
4. 发送 `https://example.com`，点击后交给系统浏览器；接收的非 Web URL 不作为网页执行。
5. 离线入队、重启、重试后检查实体仍在；升级保留 0.1.0 的消息数据。

自动化覆盖协议往返、UTF-16、范围校验、编辑与同名提及、草稿、数据库重启与 Flow、数据库迁移以及 Compose 链接/提及点击。真实跨端消息与通知仍需 dev 环境账号联调验收。
